Detailed Description

Driver for the XSPI_TARGET peripheral on RX MCUs. This module implements the SPI Flash Interface.

Overview

The XSPI_TARGET peripheral supports xSPI access SRAM, and it interfaces with these devices to perform data I/O Operations.

Please note that this document will reference the xSPI protocol to which XSPI is a subset. The XSPI_TARGET peripheral is compatible with a variety of xSPI protocol operating modes.

Features

The XSPI_TARGET driver has the following key features to support the xSPI device:

  • Perform data I/O Operation
  • Can be configured with xSPI devices on either of the 2 channels
  • Support for standard SPI frames, xSPI Protocol 1.0, xSPI Protocol 2.0, and xSPI Protocol 2.0 Extended frames.

Clock Configuration

The signals to the xSPI target device are derived from OCTACLK. OCTACLK must be set to twice the desired xSPI_CLK signal frequency. This allows data to be latched on either clock edge for Dual-Data-Rate modes (4S-4D-4D or 8D-8D-8D).

Please refer to the Hardware User Manual for the clocks which control the XSPI_TARGET registers. These along with OCTACLK can be set on the Clocks tab of the RA Configuration editor.

Pin Configuration

The following pins are available to connect to an external XSPI device:

  • XSPIn_CK: clock output (XSPICLK / 2)
  • XSPIn_DS: data strobe signal
  • XSPIn_CS0: device 0 select
  • XSPIn_IO0: Data 0 I/O
  • XSPIn_IO1: Data 1 I/O
  • XSPIn_IO2: Data 2 I/O
  • XSPIn_IO3: Data 3 I/O
  • XSPIn_IO4: Data 4 I/O
  • XSPIn_IO5: Data 5 I/O
  • XSPIn_IO6: Data 6 I/O
  • XSPIn_IO7: Data 7 I/O
Note
Data pins can be configured with IOPORT_CFG_DRIVE_6 or IOPORT_CFG_DRIVE_8 according to the Electrical Characteristics chapter.
Chip Select pins should be configured with at least IOPORT_CFG_DRIVE_4.

Usage Notes

Usage Notes for xSPI support

XSPI Controller module will access SRAM via the XSPI Target module. So the protocol-specific configuration of the XSPI Target module must be mapped to XSPI Controller module.

Protocol mode supported:

  • 1S-1S-1S
  • 4S-4D-4D
  • 8D-8D-8D

XSPI Target module can config can configure itself, or it can be configured by the XSPI Controller module.

Access mode:

  • Register Access Mode:
    • XSPI Controller module can read register of XSPI Target module
    • XSPI Controller module can write register of XSPI Target module
    • XSPI Controller module can change IO protocol mode of XSPI Target module
    • XSPI Controller module can reset XSPI Target module
  • Memory Access Mode:
    • XSPI Controller module can read memory of XSPI Target module
    • XSPI Controller module can write memory of XSPI Target module

xSPI Commands

The command of XSPI Target has 4 types:

  • Read memory command
  • Read register command
  • Write memory command
  • Write register command

The command of XSPI Target module can be modified. If a command set is not found, an FSP_ERR_INVALID_MODE error code will be returned.

Examples

XSPI Target Basic Example

This is a basic example of minimal use of the XSPI Target in an application.

void r_xspi_target_basic_example (void)
{
/* Open the XSPI instance. */
fsp_err_t err = R_XSPI_TARGET_Open(&g_xspi_target_ctrl, &g_xspi_target_cfg);
assert(FSP_SUCCESS == err);
/* (Optional) Change SPI to DOPI mode */
err = R_XSPI_TARGET_SpiProtocolSet(&g_xspi_target_ctrl, SPI_FLASH_PROTOCOL_8D_8D_8D);
assert(FSP_SUCCESS == err);
err = R_XSPI_TARGET_Close(&g_xspi_target_ctrl);
assert(FSP_SUCCESS == err);
}
