Voltage Detection Interface
Interfaces » Monitoring

Detailed Description

Interface for Voltage Detection.

Summary

The VOLTAGE DETECTION driver provides functions for configuring the VOLTAGE DETECTION voltage monitors and detectors.

◆ voltage_detection_negation_delay_t

enum voltage_detection_negation_delay_t

Negation delay of VOLTAGE DETECTION reset signal follows reset or voltage in range

Enumerator
VOLTAGE_DETECTION_NEGATION_DELAY_FROM_VOLTAGE 

Negation follows a stabilization time (tVDn) after VCC > Vdet1 is detected. If a transition to software standby or deep software standby is to be made, the only possible value for the RN bit is VOLTAGE_DETECTION_NEGATION_DELAY_FROM_VOLTAGE

VOLTAGE_DETECTION_NEGATION_DELAY_FROM_RESET 

Negation follows a stabilization time (tVDn) after assertion of the VDn reset. If a transition to software standby or deep software standby is to be made, the only possible value for the RN bit is VOLTAGE_DETECTION_NEGATION_DELAY_FROM_VOLTAGE
