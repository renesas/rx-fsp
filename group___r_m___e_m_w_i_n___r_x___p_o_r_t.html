Detailed Description

SEGGER emWin serial LCD port for RX MCUs.

Overview

The SEGGER emWin RX Serial Port module provides the configuration and serial display support necessary to use emWin with supported LCD controllers on RX MCUs. The port connects the emWin FlexColor display driver to an FSP SPI lower driver and uses optional GPIO pins to control the display signals.

Note
The display port is managed internally by emWin through GUI_X_Config, LCD_X_Config, and LCD_X_DisplayDriver. Please consult the SEGGER emWin User Guide (UM03001) for details on how to use emWin in your project.

Features

The SEGGER emWin RX Serial Port module supports the following features:

  • Runtime configuration of the GUI heap, display size, color depth, LCD controller, orientation, write cache, SPI lower driver, and optional GPIO pins
  • ST7715 and ILI9341 serial LCD controller profiles
  • Synchronous command and data transfers through an FSP SPI lower driver
  • emWin graphics, bitmap, and widget output through the serial LCD FlexColor driver
  • FreeRTOS, ThreadX, and bare-metal support

Hardware Configuration

Add one FSP SPI lower driver instance and configure its channel, bitrate, pins, transfer support, and interrupts for the LCD panel. The RX Serial Port uses 8-bit SPI transfers.

Configure the required GPIO pins in the BSP pin configuration. Data/command and LCD chip select are normally required. Display enable, backlight, and reset can be enabled when required by the hardware. Configure each software-controlled chip-select pin as an output with an initial high level.

Display Configuration

Set the LCD controller, horizontal and vertical pixel counts, color depth, orientation, and write-cache selection in the RX Serial Port module configuration.

The horizontal and vertical pixel properties specify the physical panel dimensions before rotation. The port provides the rotated logical dimensions to emWin when a 90-degree clockwise or counter-clockwise orientation is selected.

For 16-bpp output, enable Use Write Cache to select the cached FlexColor controller mode. This runtime configuration is applied when GUI_Init() initializes the display.

Library Configuration

emWin is provided as a pre-compiled library. To maximize compatibility the build-time options are configured as follows:

#define GUI_OS (1) // Context switch support enabled
#define GUI_MAXTASK (1) // One task supported by default
#define GUI_NUM_LAYERS (1) // Single display layer
#define GUI_SUPPORT_TOUCH (0) // Touch support excluded from this port
#define GUI_SUPPORT_MOUSE (0) // Mouse not supported by this port
#define GUI_SUPPORT_MEMDEV (1) // Memory devices available
#define GUI_WINSUPPORT (1) // Window manager available
#define GUI_SUPPORT_BIDI (1) // Bidirectional text enabled
#define GUI_DEBUG_LEVEL (2) // Parameter and consistency checks enabled (no logging)

All other options are left at the default settings in GUI_ConfDefaults.h.

Usage Notes

Getting Started

To get started with emWin on an RX serial LCD project the following must be performed:

  1. Open the RX Configuration editor for your project
  2. Add emWin to your project in the Stacks view by clicking New Stack -> SEGGER -> SEGGER emWin
  3. Add the SEGGER emWin RX Serial Port module
  4. Add and configure an FSP SPI lower driver instance
  5. Configure the LCD controller, display size, color depth, orientation, write cache, and required GPIO pins
  6. Ensure the lower-driver interrupts are enabled
  7. Confirm the application stack and the emWin GUI heap are configured as needed
  8. Click Generate Project Content to save and commit configuration changes

At this point the project is ready to build with emWin. Call GUI_Init() before using emWin drawing APIs. The port opens the configured SPI lower driver and initializes the LCD controller during display initialization. Please refer to the SEGGER emWin User Guide (UM03001) as well as demo and sample code for details on how to create a GUI application.

Serial LCD Operation

emWin calls LCD_X_Config to configure the display layer and LCD_X_DisplayDriver to initialize and control the serial LCD. The port opens the configured SPI lower driver during LCD controller initialization. The application does not need to open the lower SPI driver or call RM_EMWIN_RX_PORT_Write directly for emWin drawing. The lower driver remains responsible for the SPI clock, bitrate, pins, transfer engine, and interrupts. The port provides a bounded SPI transfer wait that reports completion, callback failure, and timeout. Call GUI_Exit() before RM_EMWIN_RX_PORT_Close(&g_rm_emwin_rx_port_ctrl) when explicit teardown is required. Closing the port releases the configured SPI lower driver.

RTOS Support

RTOS support is selected by the EMWIN_CFG_RTOS configuration macro. By default this macro follows BSP_CFG_RTOS.

  • EMWIN_CFG_RTOS == 2: FreeRTOS
  • EMWIN_CFG_RTOS == 1: ThreadX
  • EMWIN_CFG_RTOS == 0: Bare metal

Limitations

Developers should be aware of the following limitations when using SEGGER emWin RX Serial Port:

  • LCD reads are not supported
  • One display layer is supported
  • Because emWin is provided as a pre-compiled library, the build-time options are fixed. See the Library Configuration section for the supplied configuration

Examples

Basic Example

This is a basic example demonstrating a simple emWin application on an RX serial LCD. The screen is cleared to white, a title bar is drawn, and "Hello World!" is printed in the center.

Note
emWin manages the configured SPI lower driver internally for display output; the lower driver does not need to be opened directly by the application.
void emWinTask (void)
{
/* LCD controller initialization opens the configured SPI lower driver. */
if (0 != GUI_Init())
{
return;
}
int const x_size = LCD_GetXSize();
int const y_size = LCD_GetYSize();
GUI_SetBkColor(GUI_WHITE);
GUI_Clear();
GUI_SetColor(GUI_BLUE);
GUI_FillRect(0, 0, x_size - 1, RM_EMWIN_RX_PORT_EXAMPLE_TITLE_HEIGHT);
GUI_SetColor(GUI_WHITE);
GUI_SetBkColor(GUI_BLUE);
GUI_DispStringHCenterAt("RX Serial emWin", x_size / 2, RM_EMWIN_RX_PORT_EXAMPLE_TITLE_TEXT_Y);
GUI_SetBkColor(GUI_WHITE);
GUI_SetColor(GUI_BLACK);
GUI_DispStringHCenterAt("Hello World!", x_size / 2, y_size / 2);
while (1)
{
GUI_Delay(20);
}
}
Note
For further example code please consult SEGGER emWin documentation, which can be downloaded here, as well as the Quick Start Guide and example project(s) provided with your Evaluation Kit (if applicable).
