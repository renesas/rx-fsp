Detailed Description

Interface for PCIF functions.

Summary

Phase Counting Interface(PCIF) interface provides APIs and definitions for motor communication.

◆ open

fsp_err_t(* pcif_api_t::open) (pcif_ctrl_t *const p_ctrl, pcif_cfg_t const *const p_cfg)

Initial configuration.

Implemented as
  • R_PCIF_Open()
Precondition
Peripheral clocks and any required output pins should be configured prior to calling this function.
Note
To reconfigure after calling this function, call pcif_api_t::close first.
Parameters
[in]p_ctrlPointer to control structure. Must be declared by user. Elements set here.
[in]p_cfgPointer to pin configuration structure. All elements of this structure must be set by user.
